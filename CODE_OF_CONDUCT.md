# Code of conduct

BetterDrop follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep criticism about the code, not the person. Harassment, insults and discrimination aren't tolerated, in issues, pull requests or anywhere else the project lives.

Report anything unacceptable by opening a private [security advisory](https://github.com/Pallepadehat/BetterDrop/security/advisories/new) or contacting the maintainer through their GitHub profile. Reports are handled confidentially.
